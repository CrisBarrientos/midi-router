# Enrutador MPK Mini -> FM-1 (Android)
1. Sube el contenido de esta carpeta (incluida .github) a un repositorio de GitHub.
2. Pestana Actions -> "Build APK" -> abre la ejecucion -> descarga el artefacto "mpk-fm1-router-apk".
3. Descomprime, copia app-debug.apk al movil e instalalo (permite apps desconocidas).
